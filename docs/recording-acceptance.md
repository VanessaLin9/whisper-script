# 原生錄音第一階段：實機驗收

命令列入口：`bash scripts/record-meeting.sh`。來源由使用者選擇；不以當下音量或會議狀態判斷。
離線測試不代表下列實機驗收已通過。開始前請確認場合允許錄音。

| 情境 | 步驟 | 通過條件 |
|---|---|---|
| 首次權限 | 選系統音，拒絕螢幕與系統錄音權限，再依提示授權並重開終端機 | 拒絕時明確失敗，沒有麥克風 fallback；授權後可錄 |
| 麥克風權限 | 選兩者，拒絕麥克風權限 | 提示修復方式，不標示已成功開始雙路錄音 |
| 提早錄音 | 選系統音，先安靜 30 秒，再播放測試語音，Ctrl+C | 開頭保留安靜；後段聽得到語音；可自動轉錄 |
| AirPods 遠端音 | 戴 AirPods 開測試 Meet，選系統音 | raw 回聽能清楚聽到遠端聲音，而非環境漏音 |
| 雙路音訊 | 選兩者，自己與遠端交替說話，並說明測試時間點 | 主檔聽得到雙方；兩路原始檔均保留且時間對齊；長錄後仍同步 |
| 輸出切換 | 錄音中切換喇叭／AirPods，並在 Meet 內切換輸出 | 顯示系統預設輸出切換通知；遠端音持續進檔。Meet 內部選擇須另回聽確認 |
| 麥克風斷線 | 固定 AirPods 麥克風後斷線 | 明確提示並停止，保留已錄 WAV 與 log，不改錄其他麥克風 |
| 全段靜音 | 選系統音且全段不播放聲音，停止 | 有效性檢查攔截，不啟動 Whisper；暫存和 log 保留 |
| 停止與中斷 | Ctrl+C；另測 SIGTERM | Ctrl+C 等 WAV 關閉後轉錄；SIGTERM 只保留檔案；不覆寫既有 workspace |
| Ownership | 成功錄音後檢查 workspace | raw、音軌與 log 存在；`retained_in_workspace=true`；`recording` 記錄來源、實際開始時間及軌道；只清本次暫存 |
| 舊路徑 | 未設定來源、選單直接 Enter；再明選麥克風 | 仍使用 FFmpeg `MIC_DEVICE`，停止後自動轉錄；現有匯入／清洗／notes 流程可用 |

原生模式目前固定 48 kHz mono PCM16；`RECORDING_SAMPLE_RATE`、`RECORDING_CHANNELS` 仍供原本 FFmpeg mic 模式使用。
系統音涵蓋整個系統，不提供指定 App 篩選。長時間雙路錄音、不同麥克風、AirPods 韌體與 macOS 版本均須實測。
重新編譯的 ad-hoc 簽章可能需要重新授權；目前尚未製作正式簽章／發佈套件。
